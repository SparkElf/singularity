# 原生思源工作区与企业管理入口

## 用户目标

作为思源用户，我打开奇点时看到的主工作区应与未经修改的思源 Web 版一致；我可以从左侧 Dock 进入企业管理，但企业页面不应改变文档树、页签、编辑器、状态栏或原生快捷键。

## 交互定义

1. 启动后主工作区由思源原生 `App`、`Layout`、`Wnd`、`Tab`、`Dock` 和 `Protyle` 提供。
2. 左侧 Dock 增加一个企业管理图标，默认不抢占文件树焦点。
3. 点击图标后，原生 Dock 打开一个原生 panel；panel 内挂载企业 React 页面。
4. 关闭或切换 Dock 时，React 页面停止接收工作并销毁 iframe/model 资源。
5. 企业页的主题通过入口 URL 接收原生已解析的明暗模式，再由 React 设计系统消费；主工作区不加载 React 壳样式。

## 验收标准

- 主空间亮色和暗色截图中，顶栏、顶部页签、左/右 Dock、文档树、编辑器位置和底部状态栏与同版本原生思源基线一致；允许差异仅为新增企业入口。
- 进入企业管理后，原生工作区 DOM 结构和当前文档内容不被 React 重建或复制。
- 企业 panel 在打开、切换、关闭后无残留 iframe、监听器或请求继续写入原生工作区。
- 320px 视口下原生思源布局仍由原生响应式规则负责，企业入口不造成横向溢出。
- 企业页面加载失败时只影响企业 panel，原生文档编辑仍可继续使用。

## 测试价值口径

截图对比证明用户可见的原生布局合同；浏览器行为测试证明入口、切换和资源销毁合同；静态边界检查证明 `SpacePage` 不再是主工作区生产入口。
